# Caves of Qud 한국어 번역 용어집

> 기존 번역(strings.csv, C# 패치)에서 추출한 확정 용어 목록.
> 번역 시 이 문서를 참조하여 용어 일관성을 유지할 것.

---

## 범례

- **확정**: 기존 번역에서 일관되게 사용된 용어
- **불일치 주의**: 기존 번역에서 2가지 이상 표기가 혼재. 통일 필요
- 원문 유지 항목은 한국어 열에 원문을 그대로 기재
